### Inference

Support level: Supported hypothesis

The evidence supports a structural change in which the process now splits into two mutually exclusive branches: one containing A32 (and not A33/A34) and one containing A33/A34 (and not A32). In the later window, A25 no longer routes to A33/A34 but goes directly to A26, and A33/A34 now route to A29 instead of A26. This is directly shown by successor changes (DIR001, DIR003, DIR004), cooccurrence and order changes (REL013, REL014, REL005, REL006, REL008, REL009), and lag changes (LAG001, LAG004, LAG005, LAG010, LAG012). The number of evidence items (41) far exceeds the 0.64 expected by chance, so the overall pattern is unlikely to be a sampling artifact. A competing explanation that cannot be fully ruled out is that the two windows come from different variant mixtures without a true process change, but the consistency and directness of the routing and order evidence make this less plausible. Some individual items have low support (e.g., LAG003, LAG007, LAG009, LAG011), but they are not central to the main pattern.
