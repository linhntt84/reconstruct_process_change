### Inference

Support level: Supported hypothesis

The evidence supports a hypothesis that the process changed from a single-stage structure where a set of activities (A33–A43) were optional and directly reachable from the start activities A30/A31, to a two-stage structure where a core set (A33–A38) is mandatory and precedes a later set (A39–A43). The participation of all these activities increased from about half to nearly all traces, and the order between the core and later activities became fixed (core before later). The start activities A30 and A31 remain before the core. The order among the core activities remains mixed. The screening shows 99 qualified items against 1.2 expected by chance, so the overall difference is not a sampling artefact. A competing explanation that cannot be fully ruled out is that the later activities (A39–A43) were always part of the process but were simply not observed in the earlier window because they were rare; however, their participation jumped from near zero to near universal, which is more consistent with a structural change than with sampling variation.

Other differences: The outgoing transitions of A30 narrowed from a broad set to a core set, and A33 gained new outgoing transitions to A39–A43. These are consistent with the main hypothesis of a two-stage structure. The LAG items for A30 with A40/A41/A43 are based on only one trace in the later window and are not reliable. The LAG items for A37 with A39/A43 have only one trace in the earlier window, so they cannot support a comparison.
