### Inference

Support level: Supported hypothesis

The evidence supports a reversal in the order of a block of activities relative to A28 and A29, together with a change in how A47 connects to that block. In the earlier window, the typical order was A47 → A28 → A29 → (A19/A20/A25/A26/A27) → A30 → A34. In the later window, it is A47 → (A19/A20/A25/A26/A27) → A28 → A29 → A30 → A34. This is directly shown by the successor changes (DIR), the order reversals (REL), the position shifts (POS), and the lag changes (LAG). The number of qualifying evidence items (30) far exceeds the 0.61 expected by chance, so the overall pattern is unlikely to be a sampling artefact. The main limitation is that some LAG items have very small support in the later window (e.g., LAG001, LAG003, LAG004, LAG005 each have only 1 supporting trace), but the core evidence from DIR, POS and REL is based on substantial support (39–48 traces before, 37–44 after for the activities involved, and 200 for A29/A30/A47).

Other differences: A29 and A30 became more deterministic in their successors (A29→A30, A30→A34), which is consistent with the same chain and not a separate hypothesis.
