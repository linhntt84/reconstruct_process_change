### Inference

Support level: Supported hypothesis

The evidence supports a hypothesis that resource allocation changed across several activities, with work shifting away from a set of previously dominant resources toward a different set and toward a longer tail of other resources. The change is consistent across all seven activities that passed the screening, and the number of qualifying items (7) far exceeds the 0.005 expected by chance for the resource family. The main hypothesis is that the process now assigns these activities to a different group of resources, with a broader distribution. A competing explanation that cannot be fully ruled out is that the pool of available resources changed (e.g., some users left and new ones joined), but the evidence directly shows a redistribution of assignments. Other differences: none beyond the resource redistribution.
