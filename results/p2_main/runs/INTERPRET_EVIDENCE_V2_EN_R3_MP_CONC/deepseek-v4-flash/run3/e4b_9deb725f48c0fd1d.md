### Inference

Support level: Supported hypothesis

The evidence supports a change in resource allocation: for several activities (A01, A03, A13, A14, A17, A22, A24), the set of resources performing them changed from a diverse pool to a different, more concentrated set, and for A24 the work became fully concentrated on a single resource. The change is consistent across all eight resource indicators, and the number of qualifying items (8) far exceeds the 0.005 expected by chance for the resource family, so it is not a sampling artefact. The main limitation is that the underlying cause (e.g., a change in staffing or workload) cannot be inferred, but the observed assignment behaviour itself is directly and consistently different between the windows. No other differences (control flow or timing) were detected.
