### Inference

Support level: Supported hypothesis

The evidence supports a hypothesis that the process changed from a flexible, branching structure with multiple alternative successors and variable ordering to a fixed, linear sequence of activities. The main path appears to be A31 → A22 → A20 → A23 → A24 → A26 → A25 → A32, with each step now taken almost exclusively. This is directly shown by the successor distributions (DIR003–DIR009), the fixed order relations (REL002–REL009), and the concentrated lag distances (LAG003–LAG031). The number of qualifying items (58) far exceeds the 0.76 expected by chance, so the overall pattern is unlikely to be a sampling artefact. The main limitation is that some individual items, especially those involving A08 and A10, rest on few observations (A08 after: 26 traces; A10 after: 25 traces), and a few LAG items have support of only 1 trace in the later window, though they are consistent with the main pattern.

Other differences: A08 became rare and A10 appeared more often, but their role in the new sequence is not established. A14's successor shifted from A08 (29% before, 6.5% after) toward A15 (70% before, 89.5% after), which may be a consequence of A08's decline. [OCC001, OCC002, DIR002]
