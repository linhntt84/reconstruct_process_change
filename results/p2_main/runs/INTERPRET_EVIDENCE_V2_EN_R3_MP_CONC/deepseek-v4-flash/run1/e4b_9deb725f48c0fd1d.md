### Inference

Support level: Supported hypothesis

The evidence supports a hypothesis that resource allocation changed: the work of several activities (A01, A03, A13, A14, A17, A22) was redistributed from a broad set of resources to a smaller set of new resources, and for A24 the work became fully concentrated on a single resource. The number of resource-related evidence items (8) far exceeds the 0.005 expected by chance, and the changes are consistent across activities. A competing explanation that this is a random sampling artifact is ruled out by the screening comparison. However, the evidence does not indicate why the allocation changed, and the exact set of resources differs per activity. Other differences: none beyond the resource allocation changes.
