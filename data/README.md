# Data

## `references/` (in Git)

| File | Content |
|---|---|
| `ostovar_size3_atomic_object_ground_truth_v1.csv` | Frozen affected-activity references for the 26 evaluated Ostovar cases (fragment size 3), as used in the submitted manuscript. Unchanged. |
| `ostovar_size3_atomic_object_ground_truth_v2.csv` | Same 26 references with one correction used for version-2 scoring: Frequency, drift 1 lists all six reweighted activities (p1, p2, p3, q1, q2, q3) instead of p1, q1, q2 (column `correction_v2`). Matches the deterministic rule of `experiments/e0_parameter_setting/build_tuning_references.py` on all 26 cases. |
| `cdlg_case_ground_truth_one_per_log100_v1.csv` | Frozen references of the 100 evaluated CDLG cases (one change episode per log), as used in the submitted manuscript. Unchanged. |
| `cdlg_selected_cases_one_per_log100_v1.csv` | Case selection of the submitted manuscript (seed 20260913); agrees with the file above on log and change interval. |
| `cdlg_gold_standard.csv` | Official CDLG change points per log (used to isolate each evaluated change for E1). |

References for the held-out tuning sizes are generated by
`experiments/e0_parameter_setting/build_tuning_references.py` into `results/e0_parameter_setting/`.

## `raw/` (not in Git)

Place or symlink the raw inputs here, or point the environment variables to them.

| Path | Env var | Source |
|---|---|---|
| `raw/ostovar_characterization/` | `PCR_OSTOVAR_FULL` | Ostovar et al. "Logs Characterization" benchmark: 5 fragment sizes × atomic/composite/nested × 0/2.5/5% noise (MXML). https://drive.google.com/file/d/1xYuai8-HBrCZLSAuZMGPv7IJzOjbEsaY/view |
| `raw/paper_v1_evidence/` | `PCR_PAPER_V1_EVIDENCE` | Evidence JSON sent to the LLMs for the submitted manuscript (`artifacts/api/<run>/evidence/*.json`); used only to check that this code reproduces it. |
| (outside the repo) CDLG zips `without_noise_part_{1,2}.zip` | `PCR_CDLG` | 100 noise-free CDLG logs of Kraus and van der Aa (concept-drift-characterization, `evaluation_paper/data_collection/datasets_evaluation/without_noise`). SHA-256: part 1 `0587e6b9…5de5d`, part 2 `35858f19…78eec`. |
| (outside the repo) `ProDrift2.5.jar` | `PRODRIFT_JAR` | ProDrift 2.5 (Apromore), used unmodified for E1. SHA-256 `700f20f9…50e59c0`. |

Log naming: `<pattern>.mxml.gz` = 0% noise, `<pattern>_2.mxml.gz` = 2.5%, `<pattern>_5.mxml.gz` = 5%.
Each log has 2999 traces with two drifts; the evaluation windows are the 200 traces before
and after traces 900 and 1900, as in the manuscript.
| `ostovar_size1_references_v2.csv`, `ostovar_size5_references_v2.csv` | Evaluation references for fragment sizes 1 and 5 (78 rows each: 13 patterns × 2 drifts × 3 noise levels), derived by two independent procedures (rule and projection) with recorded decisions; see `experiments/e11a_ostovar_references/README.md`. |
